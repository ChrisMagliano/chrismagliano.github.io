Learn the concepts

What does ordinary least squares minimize?

It selects coefficients that minimize the sum of squared differences between observed and predicted values. Squaring makes large errors more influential.

What do R², MAE and RMSE mean?

R² compares squared prediction errors with predicting the mean; it can be negative on held-out data. MAE is average absolute error. RMSE is the square root of average squared error and penalizes larger mistakes more heavily.

Why use a train/test split?

Evaluating only on the same data used for fitting can be optimistic. A held-out test set provides a basic check of out-of-sample generalization. For time-series data, use a chronological split instead of random shuffling.

How does K-fold cross-validation select a model?

The training data are split into K folds. Each candidate degree is fitted K times, each time using K−1 folds and predicting the remaining fold. The average validation RMSE estimates predictive performance. Choose the degree before evaluating the separate test set. With small samples, fold-to-fold variability can be substantial.

What is the bias–variance tradeoff?

Simpler models can underfit systematic relationships (high bias), while more flexible models may become sensitive to random variation (high variance). A more complex model is not automatically worse: prefer repeated out-of-sample validation over degree alone.

Why can a high-degree polynomial overfit?

A flexible model may follow random noise instead of the underlying relationship. Compare training and test errors, and avoid extrapolating polynomials beyond the observed X range.

What are the limitations?

This browser tool handles one numeric predictor and one numeric outcome, using unregularized polynomial least squares. It does not infer causality, handle missing values, perform inference on coefficients, or establish which model will perform best on future data. Model selection uses cross-validation, not the final test set.
